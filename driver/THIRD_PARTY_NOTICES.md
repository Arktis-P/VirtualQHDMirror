# Third-Party Notices — Driver Source

No third-party virtual display driver binary is currently stored under `driver/`.

## Planned upstream

The production VQM virtual display driver is planned to derive from:

- Microsoft Windows Driver Samples — IddSample
- Repository: https://github.com/microsoft/Windows-driver-samples
- License: Microsoft Public License (MS-PL)

The exact upstream commit must be recorded when source is imported.

## Compatibility driver

Development may use a separately installed ge9/IddSampleDriver-compatible driver.

That driver is **not vendored or redistributed from this directory** and must not be silently copied into a VQM public package.

This notice is a repository engineering record, not legal advice.
