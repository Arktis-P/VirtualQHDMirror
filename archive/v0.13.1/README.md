# VirtualQHDMirror v0.13.1 archive

This directory is a runnable frozen copy of the v0.13.1 baseline from commit `0d2321419e44c80fa25690ec155f629fa405a5f2`.

Use this archive when the v0.14 development input engine is not yet suitable for daily use.

## Run

- `run.cmd`: adaptive mode
- `scripts/run-30fps.cmd`: fixed 30 FPS
- `scripts/run-60fps.cmd`: fixed 60 FPS

The archived code is intentionally not updated with v0.14 changes.
